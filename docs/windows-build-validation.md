## Проверки готовых файлов

Оба EXE проверены скриптом `packaging/windows/smoke_test.py`.
Переносимый EXE копировался в отдельную временную папку; в PATH дочернего
процесса оставался только Windows System32. База создавалась во временной
папке с пробелами и кириллицей. Это проверка автономного запуска на текущем
Windows-компьютере, без отдельной чистой виртуальной машины.

Успешно проверены:

- Запуск собственного Python backend и встроенного Node.js.
- Главная страница, 8 JavaScript/CSS ресурсов и четыре маршрута документа.
- Отклонение посторонних Host/Origin; отдельный Origin для desktop backend.
- Повторный запуск без второго экземпляра серверов.
- Загрузка `samples/01_simple_manual_numbering.docx`, разбор и подтверждение сторон.
- Построение протокола из трёх строк, изменение согласованной редакции.
- Экспорт DOCX с проверкой изменённого текста внутри `word/document.xml`.
- Сохранение изменений после завершения и повторного запуска EXE.
- Освобождение портов после закрытия приложения.
- Понятная ошибка при занятом порте без остановки его владельца.
- Отображение русского окна запуска и завершение серверов кнопкой закрытия окна.
- Установка в тестовую папку, запуск установленного EXE и деинсталляция;
  запись деинсталлятора и тестовые файлы программы после удаления отсутствуют.

Локальные журналы проверки: `build/windows/portable-smoke.log`,
`installed-smoke.log`, `install-smoke.log`, `uninstall-smoke.log`.

## Проверки исходного проекта

- Production-сборка frontend с проверкой типов и ESLint: успешно.
- Frontend: 60 тестов успешно.
- Backend: 272 теста успешно, один существующий тест производительности не прошёл.
  `test_oversized_lvl_text_is_rejected_before_repeated_scan` требует менее 1 секунды;
  результат на этом компьютере — 1,55 секунды, повторный отдельный запуск — 1,47 секунды.
  Реализация обработки нумерации и этот тест в рамках упаковки не менялись.
- После настройки desktop-портов: 64 проверки health/API и защиты загрузки успешно.

## Запуск и данные

Открывается браузер по адресу `http://127.0.0.1:17341`; backend слушает
`127.0.0.1:17342`. Версия для разработки сохраняет порты 3000/8000.
Данные обеих Windows-версий находятся в `%LOCALAPPDATA%\DisagreementProtocol`.
Деинсталлятор удаляет программу, сохраняя пользовательские данные.

Повторная сборка: `scripts/build-windows.ps1`. Подробности — в основном README.
