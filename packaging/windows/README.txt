ПРОТОКОЛ РАЗНОГЛАСИЙ — Windows x64, версия 0.1.0

Системные требования: Windows 10/11 x64 и современный браузер.
Python, Node.js, Microsoft Word и подключение к интернету для работы не нужны.

ПЕРЕНОСИМАЯ ВЕРСИЯ
Запустите DisagreementProtocol-Portable.exe. При каждом запуске компоненты
распаковываются во временную папку, поэтому первый старт может занять время.
Для передачи приложения достаточно одного EXE.

УСТАНОВКА
Запустите DisagreementProtocol-Setup-0.1.0-x64.exe.
Установка выполняется для текущего пользователя без прав администратора.
После установки приложение доступно в меню «Пуск».

РАБОТА
Интерфейс открывается в браузере по адресу http://127.0.0.1:17341.
Оставьте окно «Протокол разногласий» открытым на время работы.
Закрытие этого окна останавливает приложение. Закрытие вкладки браузера
не останавливает приложение. Повторный запуск открывает интерфейс.
Порты 17341 и 17342 должны быть свободны; доступ разрешён только с этого ПК.

ДАННЫЕ
База, загруженные документы и журналы хранятся в:
%LOCALAPPDATA%\DisagreementProtocol
Обе версии используют одну и ту же папку. Данные сохраняются при обновлении,
удалении программы и переносе EXE. Для переноса документов на другой ПК
закройте приложение и скопируйте папку данных отдельно.

ДИАГНОСТИКА
Журналы: %LOCALAPPDATA%\DisagreementProtocol\logs
Кнопка «Открыть папку данных» находится в окне приложения.
Параметры командной строки: --no-browser, --data-dir "путь".

Сборка не подписана цифровым сертификатом издателя: Windows SmartScreen
может показать предупреждение о неизвестном приложении.
Контрольные суммы файлов находятся в SHA256SUMS.txt.
